# ふっきんちゃんが一晩でやってくれました

UTAU音源の構築と設定編集をまとめて行う、Windows／macOS向けのデスクトップアプリです。既存音源の確認・編集と、録音ファイルからの新規音源作成を扱います。v0.1.0はテスト版です。

ElectronとReactで動作し、音源の読み書きはローカルで行います。通常の利用にローカルHTTPサーバー、CDN、外部フォントは必要ありません。

## macOSでの起動について

アプリを「アプリケーション」フォルダに移動した後、ターミナルで次のコマンドを実行してください。

```sh
xattr -rc "/Applications/ふっきんちゃんが一晩でやってくれました.app"
```

## ダウンロード

テスト版は[Releases](https://github.com/abschan-dayo/Utau-Setup/releases)からダウンロードできます。WindowsはポータブルZIPを解凍し、フォルダ内のEXEを起動してください。macOSはApple Silicon向けの`.app.zip`を用意しています。

## 主な機能

- **新規音源の作成**：WAVまたは収録フォルダをまとめて読み込み、単音階・多音階を自動判定します。判定は手動で変更できます。指定先に音源フォルダを作り、必要な`oto.ini`、`character.txt`、`readme.txt`を生成します。
- **既存音源の確認と編集**：フォルダ選択またはドラッグ＆ドロップで開きます。`character.txt`と`character.yaml`の基本情報をタブで編集し、内容を相互にコピーできます。未保存の変更はまとめて保存できます。
- **画像と音源情報の確認**：アイコン・立ち絵を選択してプレビューし、音源内にコピーして相対パスで保存します。UTAU／OpenUtauでの音源情報の表示を模した確認画面もあります。
- **`prifixmap`**：`prefix.map`を読み込み、収録音高やFRQと対応する`oto.ini`のsuffixから割り当てを生成できます。音域・音高ごとの編集、複数選択、全選択、保存に対応します。
- **VoiceColorとPhonemizer**：色別の音域を確認・編集します。`default_phonemizer`は候補からの選択、直接入力、解除ができます。
- **周波数表**：FRQ・LLSM・PMKを拡張子別に集計・表示し、ファイル単位または拡張子単位で削除できます。WAVからのFRQ一括生成と、利用者が選択したMoresamplerによるLLSM一括生成・再生成に対応します。
- **READMEと階層確認**：`readme.txt`の生成・編集、音源内ファイル階層の表示、`$read`の検出・削除に対応します。
- **プラグイン**：配布前チェッカーを標準搭載。プラグインを追加すると左のメニューに専用項目が増え、そこでコマンドを実行できます。音源内テキストの読み取り・書き込みは権限を分けて管理します。「プラグイン管理」から制作用の雛形を保存できます。ソース内の例は`plugin-template/`にあります。

ライト・ダーク・システムテーマ、処理中の表示、操作時の通知音を備えています。アプリ設定ではバージョン、動作環境、CPU、Electron、プラグインAPIバージョンを確認できます。

## 使い方

起動後に「既存音源を開く」か「新規音源を作成」を選びます。既存音源はフォルダを選択するか画面へドロップしてください。変更内容を確認して保存できます。新規音源は録音ファイルまたは収録フォルダをドロップし、保存先と音源名を指定します。

Windows x64のポータブル版は、解凍したフォルダ内のEXEを起動します。EXEと`plugins/`を同じ親フォルダに置いてください。起動時に必要なアプリ本体を一時領域へ展開します。EXEだけを移動すると標準プラグインは表示されません。

Windows配布版では、書き込み可能な場所に置いた場合、設定を`data/`、キャッシュを`cache/`、ログを`logs/`へ保存します。これらはEXEと同じ親フォルダに作られます。書き込みできない場所ではOS標準のユーザーデータ保存先へ切り替わります。macOS版はOS標準の保存先を使います。

macOS Apple Silicon版は`.app`をビルド済みです。配布ZIPをmacOS上で展開してください。macOSでの画面表示と操作はまだ確認できていません。

LLSM生成には別途Moresamplerの指定が必要です。Moresampler本体は同梱していません。

## プラグインの作成

「プラグイン管理」画面の「雛形を保存」で制作例を取り出し、`plugin.json`と`main.js`を編集してください。完成したフォルダは「フォルダから追加」で読み込みます。ソースでは[雛形の説明](plugin-template/PLUGIN_API.md)も参照できます。

`plugin.json`の`author`に製作者名義を記入すると、追加確認画面とプラグイン管理画面に表示されます。現行のプラグインAPIバージョンは`1`です。

プラグインのコードはWeb Workerで実行され、音源内テキストへのアクセスは専用APIを通します。書き込みを伴う実行では、その都度確認します。現時点ではコマンド型の追加機能に対応し、独自画面の追加には対応していません。

## 保存と文字コード

UTF-8、UTF-8 BOM、ANSI (CP932)と元の改行形式を扱います。元のバイト列を安全に再現できないファイルは読み取り専用にします。保存前に外部で変更されていないか確認し、一時ファイルを使って置き換えます。保存・再生成・削除でバックアップは作成しません。

## ソースから起動・ビルド

Node.js `^20.19.0` または `>=22.12.0` が必要です。

```text
npm ci
npm start
```

```text
npm run check:privacy
npm run build
npm run package:win
npm run package:win:portable
npm run package:mac
```

`package:win`と`package:win:portable`はWindows上で、`package:mac`はmacOS上で実行してください。生成物はGitの管理対象外です。

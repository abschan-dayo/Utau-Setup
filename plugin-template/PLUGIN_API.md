# プラグイン雛形

このフォルダをコピーし、`plugin.json`と`main.js`を編集します。アプリの「プラグイン」画面で、コピーしたフォルダを選択して追加してください。プラグインはアプリのユーザーデータ領域へコピーされます。コードを更新する場合は、アプリ内で削除してから追加し直します。

`plugin-api.d.ts`にはAPIの型を記載しています。`main.js`を対応エディタで開くと、補完と型の確認に使えます。配布時に必要なファイルは`plugin.json`と`main.js`の2つです。

## plugin.json

- `apiVersion`: 現在は`1`
- `id`: 英小文字で始まる英小文字・数字・`.`・`_`・`-`のID。3～64文字
- `name`、`version`、`description`: 表示名、`1.0.0`形式のバージョン、短い説明
- `author`: プラグイン管理画面と追加確認画面に表示する製作者名義。80文字以内の1行。未指定なら「未設定」と表示
- `permissions`: `voicebank:read`、`voicebank:write`。書き込みには読み取りも必要
- `commands`: プラグイン画面に表示するボタン。各項目に`id`と`title`を指定

## main.js

`globalThis.utauPlugin = { async run(command, api) { ... } };`を定義します。`command`には押されたボタンのIDが渡されます。戻り値は画面に表示されます。

`api.voicebank.name`は選択中の音源フォルダ名です。

`await api.listFiles()`は音源内のファイルの相対パス一覧を返します。読み取り権限が必要です。

`await api.readText('relative/file.txt')`はUTF-8のテキストを返します。ファイルがなければ`null`です。読み取り権限が必要です。第2引数に`'cp932'`または`'auto'`を指定すると、ANSI (CP932)の読み取りもできます。

`await api.writeText('relative/file.txt', '内容')`はUTF-8で保存します。書き込み権限が必要です。既存ファイルは同じ実行中に先に`readText`で読み込み、外部変更がない場合だけ置き換えます。新規ファイルは既存フォルダ内に作成できます。

パスは音源ルートからの相対パスを`/`区切りで指定します。対象は`.txt`、`.ini`、`.yaml`、`.yml`、`.json`、`.csv`、`.tsv`、`.map`に限ります。1ファイルあたり1MBまでです。CP932などUTF-8以外の既存ファイルは読み取り専用です。編集にはアプリ本体の機能を使ってください。

プラグインはNode.js、Electron、ネットワーク、任意のローカルファイルへ直接アクセスできません。処理は20秒以内に完了してください。プラグインの書き込みは実行前に利用者へ確認されます。画面に独自のReactコンポーネントを追加するAPIは現時点ではありません。
